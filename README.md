# 🤖 TechCorp AI: Smart Arabic HR Onboarding Assistant

An interactive, AI-powered HR onboarding chatbot built during the **Kanz AI Hackathon**. Designed to streamline employee onboarding, answer policy inquiries in Arabic, and provide continuous chat persistence.

## 🚀 Features
- **Arabic NLP & Context Awareness:** Delivers accurate answers to employee queries regarding company policies in Arabic.
- **Client-Side Persistence:** Automatically saves conversation state using `localStorage`.
- **Modern UI:** Built with React and designed for seamless employee interactions.

## 🛠️ Tech Stack
- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **AI Engine:** Claude API & Agentic AI Workflows
- **Platform & Tools:** Replit, GitHub, n8n
